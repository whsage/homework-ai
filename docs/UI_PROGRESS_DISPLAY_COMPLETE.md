## 🔄 工作流程

### 对话流程
```
1. 学生打开SmartChat
   ↓
2. 自动加载诊断信息
   - 查询知识图谱
   - 获取技能掌握度
   - 识别薄弱环节
   ↓
3. 显示进度UI
   - 整体掌握度
   - 各技能点详情
   - 薄弱技能提示
   ↓
4. 学生与AI对话
   ↓
5. 每次对话后自动更新
   - 重新诊断
   - 更新进度显示
   - 刷新薄弱技能提示
```

### 更新逻辑
```javascript
// 每次对话后触发
useEffect(() => {
  loadDiagnosis();
}, [topicId, messages]); // messages变化时更新

// 诊断函数
const loadDiagnosis = async () => {
  const result = await KnowledgeAssessment.diagnose(user.id, topicId);
  setDiagnosis(result);
  // UI自动刷新
};
```
